# Заголовок PR

Формат:

```
<type>(<scope>): <KEY-123> <summary>
```

Заголовок PR становится заголовком squash-коммита в основной ветке, поэтому он
подчиняется правилам коммита, а не правилам заголовка тикета. Ключ тикета в
заголовке — то, по чему интеграция Jira с GitHub привязывает PR к тикету.

## Типы

Список из гайда Angular:
https://github.com/angular/angular/blob/main/contributing-docs/commit-message-guidelines.md
(снято 2026-09-03). Других типов нет; `chore` и `style` в списке отсутствуют
намеренно.

| Тип | Когда |
| --- | --- |
| `feat` | новая возможность |
| `fix` | исправление дефекта |
| `perf` | изменение кода ради производительности |
| `refactor` | изменение кода, которое не чинит дефект и не добавляет возможность |
| `test` | добавление недостающих тестов или правка существующих |
| `docs` | только документация |
| `build` | сборка и внешние зависимости |
| `ci` | конфигурация и скрипты CI |

PR с несколькими типами работы получает тип по главному изменению — тому, ради
которого PR открыт. Рефакторинг рядом с фичей — всё равно `feat`.

## Scope

У Angular scope — имя затронутого пакета. Здесь — сервис или домен, которого
касается PR: `schedule`, `orders`. Два сервиса одного домена — имя домена.
Изменение общего пакета без конкретного сервиса — имя пакета. Изменение по
всему репозиторию (тесты, документация, CI) — scope пустой: `ci: KEY-123 …`.

Имя scope пишется так, как каталог или сервис называется в репозитории, без
сокращений.

## Summary

- императив, настоящее время: `add`, не `added` и не `adds`;
- с маленькой буквы;
- без точки в конце;
- на английском;
- короче, чем строка, которую пришлось бы переносить: ключ и scope уже заняли
  место.

## Примеры

| Изменение | Заголовок |
| --- | --- |
| Экспорт статусов рейсов в новый топик, два сервиса | `feat(schedule): ABC-5312 export status changes to kafka` |
| Неверный расчёт флага в маппере | `fix(schedule): ABC-5320 compare departure_passed with computed departure time` |
| Индекс под тяжёлый запрос | `perf(orders): ABC-5340 add index on orders.user_id` |
| Общий пакет, без сервиса | `refactor(pkg/events): ABC-5351 split envelope from payload` |
| Только CI | `ci: ABC-5360 cache go modules between jobs` |

## Когда правило репозитория другое

`README.md` или `CONTRIBUTING.md` репозитория может задавать свой формат:
ключ первым, без типа, другой разделитель. Тогда действует формат репозитория:
его читает автоматика (линковка Jira, генератор changelog), и заголовок не по
формату она не поймёт. Прочитай эти файлы до того, как писать заголовок.
