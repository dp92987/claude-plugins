---

Разбери состояние git worktrees и доложи пользователю.

Аргументы: `$ARGUMENTS` — необязательные.

- Путь означает каталог для обхода. Без пути бери текущий каталог.
- `--clean` означает, что пользователь заранее разрешил удаление безопасных
  деревьев. Без него ограничься отчётом: он попросил разобраться, а не убирать.

Дальше работай по инструкции в
`${CLAUDE_PLUGIN_ROOT}/skills/worktree-janitor/SKILL.md`. Там порядок шагов,
значения статусов, разбор частых ошибок в определении «слито/не слито» и
формат отчёта. Прочитай её целиком, прежде чем запускать сканер.

Правило безопасности действует и с `--clean`: дерево с файлами из `.gitignore`
не удаляется молча. Назови такие файлы и спроси отдельно.
