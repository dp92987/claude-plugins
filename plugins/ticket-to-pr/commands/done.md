argument-hint: "<ссылка на тикет, KEY-123 или номер PR>"
---

Режим **done**: для `$ARGUMENTS` найди PR, проверь, что он зелёный, смержи
его способом из раздела «Мерж» профиля, доведи тикет до статуса `Финиш:` из
раздела «Статусы» и убери ворктри и локальную ветку тикета. Тикет с
открытыми хвостами — разделом «После мержа» или критерием, не проверенным
после выката, — в `Финиш:` не уходит: спроси, что из них сделано, остальное
перечисли в отчёте. Вызов команды —
разрешение на мерж и уборку, подтверждения не спрашивай; не зелёный PR не
мержится ни при каких флагах, а ворктри с несмерженным не удаляется.

Работай по `${CLAUDE_PLUGIN_ROOT}/skills/ticket-to-pr/references/done.md`,
шаги профиля, статусов и журнала — по
`${CLAUDE_PLUGIN_ROOT}/skills/ticket-to-pr/SKILL.md`. Прочитай done.md целиком до
начала: там как найти PR по тикету, что считается зелёным, почему мерж
привязан к проверенному коммиту, когда ворктри можно удалять и формат отчёта.

PR уже смержен (повторный вызов после хвостов) — мерж пропускается, дальше
хвосты и статус.

Аргумент пуст — возьми PR текущей ветки, если её имя содержит ключ тикета;
иначе спроси тикет или PR одним вопросом и первым вариантом предложи PR, с
которым сессия работала.
Репозиторий не привязан к профилю — сначала настройка по
`references/setup.md`, потом мерж.
