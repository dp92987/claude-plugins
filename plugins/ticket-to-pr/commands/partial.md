Режим **partial**: перед началом покажи чеклист шагов, доступных по профилю
репозитория, вместе с открытыми вопросами тикета — одним раундом — и выполни
для тикета `$ARGUMENTS` имплементацию плюс выбранное. Имплементация в чеклист
не входит — она базовая. После этого раунда вопросов о процессе больше нет.

Работай по `${CLAUDE_PLUGIN_ROOT}/skills/ticket-to-pr/SKILL.md`. Прочитай её
целиком до начала: там состав чеклиста, зависимости шагов (пуш требует
коммита, PR — пуша, призыв — PR), сбор открытых вопросов и формат отчёта.

Аргумент пуст — спроси ссылку на тикет; чеклист и открытые вопросы — после
чтения тикета и кода, иначе спрашивать нечего.
Репозиторий не привязан к профилю — сначала настройка по
`references/setup.md`, потом чеклист.
